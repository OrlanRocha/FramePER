Manual & Funções Avançadas

Grid Flexível Moderno

O sistema de grid usa `display: grid; gap: 1rem;` para o melhor posicionamento possível.

<div class="grid grid-md-3 grid-sm-1">...</div>

Funções JavaScript (Avançado)

Os modais, dropdowns e toasts não precisam de jQuery e não pesam o navegador. Você pode chamar Toasts programaticamente via JS:

// Mostra o toast por 3 segundos dinamicamente
FramePER.showToast('meuIdDeToast');
Aviso
Fui chamado pelo JS dinâmico!

Animações Nativas

Você pode combinar classes de animação para efeitos visuais elegantes na carga da página ou interação:

  • .fade-in: Surgimento suave.
  • .slide-up / .slide-down: Entrada com movimentação.
  • .hover-scale: Aumenta o tamanho no mouse hover.
  • .hover-lift: Traz o elemento para a "frente" com sombra no hover.
