Módulo HTTP

O wrapper HTTP cuida de toda comunicação com seu backend (GET, POST, PUT, DELETE), com tratamento automático de erros, CSRF e offline.

// Exemplo de Chamada GET const response = await FramePER.Http.get('/api/users'); if(response.ok) { console.log(response.data); } // Se der erro 401, 404, 500, o próprio FramePER exibirá um alerta visual!

Toasts de Notificação

Chame notificações elegantes dinamicamente pelo JS sem sujar o seu HTML.

FramePER.Notify.success('Sucesso', 'Salvo com sucesso!', 3000); FramePER.Notify.error('Erro', 'Falha ao salvar.', 5000); FramePER.Notify.info('Aviso', 'Ação processada.');

Loaders

Tranque a interface do usuário enquanto algo crucial carrega, ou insira spinners dentro de botões.

// Travar tela FramePER.Loader.showPageLoad(); FramePER.Loader.hidePageLoad(); // Loading no botão const btn = document.querySelector('#btnSalvar'); FramePER.Loader.buttonLoading(btn, true); // Inicia FramePER.Loader.buttonLoading(btn, false); // Restaura
