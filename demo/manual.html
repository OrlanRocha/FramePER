Módulo de Tema (FramePER.Theme)

Gerencia a alternância entre modo claro e escuro respeitando a preferência do sistema operacional.

// Alternar tema manualmente (Light <-> Dark)
FramePER.Theme.toggle();

// Definir tema específico ('light' ou 'dark')
FramePER.Theme.set('dark');

// Obter tema atual em execução
const atual = FramePER.Theme.get(); // 'light' | 'dark'

Tabelas Interativas & Filtros (FramePER.UI.initTables)

Automaticamente adiciona ordenação em colunas com a classe th.sortable e pesquisa em tempo real com data-table-filter="#idTabela".

<!-- Campo de busca para filtrar as linhas da tabela em tempo real -->
<input type="text" class="input" data-table-filter="#minhaTabela" placeholder="Pesquisar...">

<!-- Cabeçalhos ordenáveis com indicadores direcionais automático (↑ / ↓) -->
<table id="minhaTabela" class="table">
  <thead>
    <tr>
      <th class="sortable">Nome</th>
      <th class="sortable">Valor</th>
    </tr>
  </thead>
</table>

Modais & Side Modals / Drawers (FramePER.UI.initModals)

Modais centrais e modais laterais deslizantes (Side Modal) disparados via atributos data-toggle="modal" e data-target="#idModal".

<!-- Side Modal / Drawer Lateral Direita -->
<div id="modalSacola" class="modal modal-side modal-side-right">
  <div class="modal-content">
    <div class="modal-header">
      <h3 class="modal-title">Título do Painel</h3>
      <button class="modal-close" data-dismiss="modal">&times;</button>
    </div>
    <div class="modal-body">Conteúdo do painel lateral...</div>
  </div>
</div>

Máscaras de Entrada & Formulários (FramePER.Form)

Formatação automática em tempo real para CPF, CNPJ, telefone celular/fixo, CEP, data e moeda brasileira (R$). Também gerencia alternância de campos de senha.

<!-- Máscaras automáticas com data-mask="..." -->
<input type="text" data-mask="cpf" placeholder="000.000.000-00">
<input type="text" data-mask="cnpj" placeholder="00.000.000/0000-00">
<input type="text" data-mask="phone" placeholder="(11) 98765-4321">
<input type="text" data-mask="cep" placeholder="00000-000">
<input type="text" data-mask="date" placeholder="DD/MM/AAAA">
<input type="text" data-mask="money" placeholder="R$ 0,00">

<!-- Alternador de visualização de senha com data-toggle="password" -->
<input type="password" id="campoSenha">
<button type="button" data-toggle="password" data-target="#campoSenha">
  <i class="icon icon-eye"></i>
</button>

Área de Transferência (FramePER.Clipboard)

Copia strings fixas ou valores de campos selecionados para o clipboard do usuário com notificação toast automática.

<!-- Atributo data-copy com valor fixo -->
<button class="btn btn-outline" data-copy="npm install frame-per">Copiar Comando</button>

<!-- Atributo data-copy-target com seletor de campo -->
<input type="text" id="chavePix" value="00.000.000/0001-99">
<button class="btn btn-primary" data-copy-target="#chavePix">Copiar PIX</button>

// Invocação programática via JavaScript:
FramePER.Clipboard.copy('Texto copiado', 'Copiado com sucesso!');

Contadores Animados (FramePER.Counter)

Animação suave de contagem com curva cúbica ease-out, acionada automaticamente quando visível na tela.

<!-- Disparo automático via IntersectionObserver -->
<span data-counter="14500" data-counter-prefix="R$ ">R$ 0</span>
<span data-counter="99.5" data-counter-suffix="%">0%</span>

// Execução programática manual:
const el = document.querySelector('#meuContador');
FramePER.Counter.animate(el, 5000, 1500); // elemento, valor, duração ms

Rolagem Suave & Voltar ao Topo (FramePER.Scroll)

Atributos declarativos para rolar a tela suavemente para o topo ou para qualquer elemento âncora.

<!-- Botão flutuante que aparece automaticamente após 300px de rolagem -->
<button class="btn btn-primary btn-icon" data-scroll-top>
  <i class="icon icon-arrow-up"></i>
</button>

<!-- Âncora para rolar suavemente até uma seção específica -->
<a href="#recursos" data-scroll-to="#recursos">Ir para Recursos</a>

// Execução programática:
FramePER.Scroll.toTop();

Módulo HTTP (FramePER.Http)

Wrapper assíncrono para requisições Fetch com tratamento global de erros HTTP, detecção de conectividade e injeção automática de token CSRF.

// Requisição GET com retorno padronizado { ok, data, status }
const res = await FramePER.Http.get('/api/usuarios');

if (res.ok) {
  console.log('Dados:', res.data);
} else {
  // Notificações de erro (401, 403, 404, 500) são disparadas automaticamente!
}

Módulo de Notificações (FramePER.Notify)

Gera alertas visuais não-bloqueantes (toasts) no canto da tela.

FramePER.Notify.success('Título', 'Mensagem de sucesso');
FramePER.Notify.error('Erro', 'Houve uma falha de conexão');
FramePER.Notify.info('Aviso', 'Atualização disponível');

Módulo de Carregamento (FramePER.Loader)

Gerencia telas de carregamento globais e spinners embutidos em botões.

// Exibir e ocultar overlay de tela inteira
FramePER.Loader.showPageLoad();
FramePER.Loader.hidePageLoad();

// Travar botão com spinner interno
const btn = document.querySelector('#meuBotao');
FramePER.Loader.buttonLoading(btn, true);  // Carregando...
FramePER.Loader.buttonLoading(btn, false); // Restaura texto original

Módulo de Segurança (FramePER.Security)

Sanitização de strings contra ataques XSS antes de inserção no DOM.

Resultado Sanitizado: 
const limpo = FramePER.Security.escapeHTML('<script>alert(1)</script>');
// Retorna: &lt;script&gt;alert(1)&lt;/script&gt;
